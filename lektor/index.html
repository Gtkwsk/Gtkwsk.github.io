Tłumaczenie (Anthropic API)

Klucz zostaje tylko w tej przeglądarce. Stawki służą wyłącznie do szacowania kosztu — sprawdź aktualny cennik na stronie Anthropic.

Jak zdobyć klucz API (5 minut)
  1. Wejdź na console.anthropic.com i załóż konto (można tym samym mailem co Claude).
  2. W menu Billing dodaj kartę i doładuj np. 5–10 $ (to wystarcza na kilka książek).
  3. W menu API Keys kliknij Create Key, nadaj nazwę (np. „Lektor”) i skopiuj klucz — pokazuje się tylko raz.
  4. Wklej klucz w pole powyżej i kliknij „Sprawdź klucz”.

Głosy

Głosy pochodzą z systemu (na Androidzie: silnik Google „Zamiana tekstu na mowę”).

Lepsze głosy na Androidzie
  1. Ustawienia telefonu → wyszukaj „Zamiana tekstu na mowę” (lub: System → Języki → Zamiana tekstu na mowę).
  2. Wybierz silnik Google → ikona ustawień → Instaluj dane głosowe.
  3. Pobierz głosy dla polskiego i języków oryginału (np. hiszpański (Hiszpania)). Jeśli jest wybór jakości, weź wyższą.
  4. Wróć tutaj i kliknij „Odśwież listę głosów”.
