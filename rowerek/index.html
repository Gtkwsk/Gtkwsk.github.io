Treningi
Laboratorium Bluetooth – tutaj podglądasz, co rowerek wysyła, i uczysz aplikację jego „języka”.
  1. Zamknij oryginalną aplikację LifeSpan (rowerek łączy się tylko z jedną naraz).
  2. Kręć pedałami (Ampera budzi się od pedałowania) i kliknij Połącz.
  3. Włącz Nagrywanie. Kręć raz wolno, raz szybko. Przy każdej zmianie wpisz znacznik, np. „teraz 80 obr/min”.
  4. Kliknij Udostępnij log i wyślij go Claude'owi – rozpisze dekoder i komendy, które wkleisz w Ustawieniach.
Jeśli lista usług jest pusta, sprawdź w aplikacji nRF Connect UUID usług rowerka i dopisz je w Ustawieniach → „Dodatkowe UUID usług”, potem połącz ponownie.

Przeliczniki (gdy rowerek czegoś nie podaje)

Bluetooth – zaawansowane
Przykład dekodera
{
  "rules": [
    {
      "char": "fff1",
      "prefix": "a1",
      "fields": {
        "power":      { "offset": 2, "type": "u16le" },
        "cadence":    { "offset": 4, "type": "u8" },
        "resistance": { "offset": 5, "type": "u8" },
        "speed":      { "offset": 6, "type": "u16le", "scale": 0.01 }
      }
    }
  ]
}
Pola: power, cadence, speed, resistance, heartRate, battery
Typy: u8 s8 u16le u16be s16le s16be u24le u24be u32le u32be
Przykład komend
{
  "char": "fff2",
  "init": ["a0 01"],
  "resistance": { "1": "a2 01", "2": "a2 02", "3": "a2 03", "4": "a2 04" },
  "led": { "1": "a3 01", "2": "a3 02" },
  "poll": [ { "hex": ["a1 00", "a1 01"], "everyMs": 500 } ]
}
init – wysyłane po połączeniu; led – numery kolorów 1–12;
poll – zapytania wysyłane cyklicznie (jeśli rowerek sam nie nadaje).
